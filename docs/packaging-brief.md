现在功能已经做完，进入**打包/分发阶段**。请基于当前 `E:\AstrBot` 项目，把它整理成可以复制到其他 Windows 电脑使用、并且别人能用自己的 DeepSeek Harness 继续修改的安装包/压缩包。具体要求：

1. **路径可移植**
   - 去掉代码和脚本里所有硬编码的 `E:\AstrBot`，改成"相对项目根目录"或环境变量解析（启动器负责设置根目录）
   - 换盘符、换目录（如 `D:\Apps\XiaoJingyu`）后必须能正常启动和运行

2. **程序与数据分离 + 首次运行向导**
   - 程序文件与用户数据（配置、记忆、人设、表情、日志、QQ 登录态）分开存放
   - 首次启动引导用户：填自己的 DeepSeek API Key、设置管理员 QQ、选择/登录 QQ 小号、检测端口占用
   - 升级程序时不覆盖用户数据

3. **密钥与个人数据脱敏**
   - 打包模板里不能包含我的 DeepSeek Key、我的 QQ 号、管理员 QQ、JWT secret、密码哈希、QQ 登录数据
   - 首次运行时生成随机 JWT secret，让用户填自己的 Key

4. **许可证与源码**
   - 附带 `LICENSES/`（AstrBot AGPL-3.0、NapCat、Electron 等）和 `SOURCE.md`（源码位置、如何二次开发、如何用 DeepSeek Harness 继续改）
   - 不内置腾讯 QQ 客户端：首次启动引导用户使用自己已安装的 QQ 或下载官方安装包；NapCat 只负责注入

5. **交付形态**
   - 首选：Portable 压缩包（解压即用，含启动器、首次向导、LICENSES、SOURCE）
   - 可选：Inno Setup 安装包（装到 Program Files、数据放 `%LOCALAPPDATA%`、创建快捷方式、开机自启选项、卸载保留数据）

6. **验收标准**
   - 在**干净 Windows 环境**（不同盘符/路径、没有 Python/Node、没有我的配置）解压后，按向导填写 Key 并扫码登录，机器人在群里能回复
   - 换一台电脑复制整个目录后仍可运行（数据目录随用户走或按选择迁移）
   - 安装包/压缩包内不含任何我的个人账号信息与 API Key
